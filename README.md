## Запуск

Откройте `index.html` или `Polushko.html` в браузере. Сборка и npm-пакеты не нужны. `script.js` подключён с `defer`.

## Что реализовано

- Массив `pagesPerDay`: `[18, 65, 42, 0, 80, 55, 30]` — прочитанные страницы за семь дней.
- `findMaximum` ищет максимум циклом и условием.
- `filterHighPaceDays` отбирает дни строго с более чем 50 страницами.
- `sumPages` считает сумму.
- `analyzeReading` считает среднее, число «ленивых» дней (≤ 20 страниц) и их долю; используется цикл `for`.
- `prompt` запрашивает имя, `alert` показывает приветствие и итог, `console.log` выводит подробности.
- Если среднее строго больше 40 страниц, выводится «Отличный темп чтения!».
- Отмена ввода имени и пустое имя обработаны отдельно.
- Результаты также отображаются на странице; учебная форма показывает локальное подтверждение без отправки данных.

## Демонстрация

1. Перейдите к разделу «Дневник чтения».
2. Откройте F12 → Console.
3. Нажмите «Показать статистику», введите имя, закройте приветствие.
4. Следующий `alert`: «Всего прочитано 290 страниц, в 3 днях темп был высоким».

Диалоги запускаются кнопкой; расчёты на странице видны сразу.

Пример консоли:

```text
Прочитано страниц по дням: [18, 65, 42, 0, 80, 55, 30]
Максимум за день: 80
Дни с высоким темпом (> 50 страниц): [65, 80, 55]
Количество «ленивых» дней: 2
Доля «ленивых» дней: 28,57%
Среднее количество страниц: 41,43
Отличный темп чтения!
```

Сумма — 290, максимум — 80, среднее — 290 / 7 ≈ 41,43. Высокий темп в 3 днях. «Ленивых» дней 2 из 7, доля — 2 / 7 ≈ 28,57%.

## Проверки и отладка

Если установлен Node.js:

```sh
node --check script.js
node --test tests/script.test.cjs
```

Шесть тестов: основной пример, границы 20 и 50, неделя без чтения, пустой массив, сохранность исходных данных и условие «среднее > 40».

Для отладки откройте F12 → Sources → `script.js`, поставьте точку останова в `analyzeReading`, нажмите «Показать статистику». Через F10 проследите значения `index`, `lazyDaysCount`, `totalPages` и возвращаемый объект. Измените массив и обновите страницу, чтобы проверить другие ветви условий.
